# Cyber Tank

A childhood memory turned into a browser-based tank combat game.

💡 Inspiration

When I was a kid, my mother bought me a Gimbot, a classic handheld Brick Game advertised as "99 in 1."

One of the games was a simple tank game where you had to defend your base from enemy attacks.

Years later, I decided to turn that childhood memory into a simple game.

In Cyber Tank: Operation Frontline, the concept is reversed: instead of defending our base, we move forward and destroy the enemy's base.

🚀 Features
⚔️ Tank combat and enemy waves
🏆 5-level progression
👾 Final enemy command base
💚 Power-ups
🚀 Plasma Bazooka
🛡️ Energy Shield
💥 Particle effects
📱 Mobile virtual joystick
🖥️ Desktop keyboard controls
🔊 Procedural sound effects
🎮 Controls

Desktop

WASD / Arrow Keys → Move
Spacebar → Shoot

Mobile

Left side → Move
Right side → Shoot

Landscape mode is recommended.

🛠️ Built With
HTML5
CSS3
JavaScript
HTML5 Canvas
Web Audio API

No game engine required.
